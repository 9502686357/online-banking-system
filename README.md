# Online Banking System

A Python and MySQL based Online Banking System that provides basic banking operations through a command-line interface.

## Features

- Create a new customer account
- Generate a unique account number
- View customer and account details
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Store customer, account, and transaction data in MySQL

## Technologies Used

- Python
- MySQL
- SQL
- mysql-connector-python
